## 五、编号使用约定（自本索引建立起生效）

1. **只递增、不复用**：新文档编号取当前最大值 +1；不再出现「同号两份」。
2. **类别前缀**：文件名以 `<编号>_<类别>_<主题>.md` 形式命名，类别取值 `评审` / `整改专项设计` / `整改任务` / `进度记录` / `索引`。
3. **引用方式**：文档内互引优先使用**文件名**（而非仅编号），避免同号歧义；历史文档中以「doc 13」形式出现的引用，按上表由**上下文类别**判定所指（评审类 → `13_致命缺陷评审_…`；任务清单 → `13_评审问题修复任务列表.md`）。
4. **历史记录不改**：`docs/notes/` 等按日期归档的笔记属当时快照，其中的路径引用不追改（检索时以上表为准）。
